# 多行候选定制版

基于 rime/weasel 0.17.4，基线提交 `9cc96e20dc71b80876b12f689bb5863c76c2a7ed`。
当前保存的构建为 `0.17.4-multiline.3`。

- 横向候选默认保持单行，按下键展开最多五行，每行沿用输入方案的 page_size。
- 上下键移动当前行，数字选择当前行候选；只有当前行显示编号，其他行保留等宽编号空间。
- 同列对齐，高亮整行；在同一可见区内切换行时，候选位置与面板尺寸不变。
- 超过底行后只上滚一行，超过顶行时反向滚动，保留其余四行。
- 返回第一页、编码改变、上屏、清空或切换方案时收起。没有新增展开动画。
- 沿用小狼毫的字体、配色和 TSF 内嵌拼音。附带的外观示例使用矩形窗口和直角高亮。
- 万象上下文调频、默认数字后量词排序、回头码调整以及上屏后立即退格回滚学习。
- 上屏自动联想保持关闭。

服务端与客户端通过能力声明协商多行响应，原候选 Boost archive 格式不变。
运行中的原版客户端继续取得单页数据，重新打开应用后加载定制版 DLL。
multiline.3 的逐行滚动只修改服务端，multiline.2 客户端可直接接收。

## 验证范围

- x86/x64 客户端编译及 x64 服务端启动通过。
- 原候选 archive 兼容检查和响应解析检查通过。
- 独立客户端会话验证展开、数字编号、按键释放、双向逐行滚动、四行内容重叠和收起。
- 实际字体测量验证固定编号槽、列对齐、整行高亮范围和五行坐标稳定，包括末行不足六词、注释显隐与标记槽。
- 万象模块在隔离词库中验证上下文学习、量词排序、回头码和关闭上屏联想。

验证程序位于 `tests/multiline`。这些检查不替代不同应用中的人工外观验收。
